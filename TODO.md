# Publii Plus — список задач

## Отложено на следующий этап

### Консольный режим (автономная публикация без открытого приложения)

**Зачем.** Content inbox по расписанию работает, только пока Publii Plus открыт. На постоянно включённой машине
(Mac mini, сервер) нужен запуск без окна: проверить inbox → импортировать → рендер → Sync — по расписанию
(cron / launchd / Планировщик заданий Windows).

**Как запускать (предложение):**

```bash
publii-plus --headless --site sparkmed --inbox --sync      # импорт из inbox и Sync, если были изменения
publii-plus --headless --site sparkmed --sync              # только рендер + Sync
publii-plus --headless --all-sites --inbox                 # все сайты с включённым inbox
publii-plus --headless --site sparkmed --inbox --dry-run   # показать, что будет сделано
```

- Код выхода: `0` — успех/нечего делать, `1` — ошибка (для cron-уведомлений), `2` — конфликты/ошибки отдельных файлов.
- Вывод: читаемый текст и `--json` для скриптов; запись в журнал inbox (тот же, что в интерфейсе, триггер `cli`).

**Как устроить:**
1. В `app/main.js` (правка ядра, одна строка `PUBLII-PLUS`) — если есть `--headless`, окно не создаётся, вместо этого
   вызывается `app/back-end/plus/headless.js`.
2. `headless.js` инициализирует то же, что приложение (пути к данным, `app.sites`, базы сайтов) без `BrowserWindow`,
   берёт сервис `content-inbox` и его `publisher` (уже работают без интерфейса), выполняет команду и завершает процесс.
3. Блокировка: файл-замок в `config/`, чтобы не запускать вторую копию и не мешать открытому приложению
   (если окно открыто — либо выйти с сообщением, либо передать задачу открытому приложению).
4. Пароли серверов и токены — из связки ключей, как сейчас. На macOS связка доступна из launchd-агента пользователя
   (не из root-cron); в документации описать `LaunchAgents`-plist. На Linux-сервере без связки — зашифрованное хранилище
   Electron (`safeStorage`) или переменные окружения для токенов.
5. Electron без экрана: macOS/Windows — скрытый запуск; Linux-сервер — `xvfb-run` или `--headless`/`--disable-gpu`
   (проверить, что рендер и Sync не требуют дисплея).
6. Опционально позже: режим `--watch` (держать процесс и проверять каждые N минут) и вебхук от GitHub
   (если машина доступна из интернета).

**Проверки:** спеки на разбор аргументов и коды выхода; E2E — запуск `electron app --headless` с фейковым GitHub и
ручным деплоем в папку (как в E2E Content inbox), повторный запуск при открытом приложении, нет сети.

**Документация:** раздел в `FORK.md` + примеры для macOS (launchd), Linux (systemd timer / cron), Windows (Task Scheduler).
